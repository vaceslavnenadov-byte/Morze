# Морзе-приёмник для Android

Приложение слушает звук через микрофон и в реальном времени расшифровывает азбуку Морзе
(русский алфавит или латиница, цифры, знаки препинания).

## Возможности

- Автоматический поиск частоты тона (300–2000 Гц) или ручная настройка.
- Скорость в группах в минуту (5–60 гр/мин): «Авто-скорость» подстраивается на ходу,
  начиная с выбранного значения; без авто скорость фиксирована — удобно, когда она
  известна заранее (тогда и первые знаки принимаются верно).
- Порог громкости (−100…−10 дБ): тон тише порога игнорируется. Порог отмечен на шкале
  уровня, рядом показан текущий уровень в дБ. Крайнее левое положение — порог выключен.
- Работа в шуме: адаптивный порог по уровню шума и сигнала, фильтр щелчков.
- Переключатель «Русский / Латиница» (коды букв в азбуке общие, меняется только расшифровка).
- Индикатор тона, уровень сигнала, текущий принимаемый код (• −), скорость в зн/мин и WPM.
- Код «ошибка» (8 точек) стирает последнее слово.
- Копирование принятого текста.

## Как получить APK

Каждый push собирается в GitHub Actions (вкладка **Actions** → последний запуск →
артефакт **morze-apk**). Внутри `app-debug.apk` — его можно установить на телефон
(Android 7.0 и новее), разрешив установку из неизвестных источников.

Локальная сборка (нужен Android SDK и JDK 17):

```bash
./gradlew assembleDebug
```

Тесты декодера (генерируют сигнал Морзе с шумом и проверяют расшифровку):

```bash
./gradlew testDebugUnitTest
```

## Как это работает

Код в `app/src/main/java/com/morze/app/dsp` не зависит от Android:

1. **`FrequencyTracker`** — БПФ (окно ~93 мс) ищет устойчивый пик спектра — частоту тона.
2. **`goertzelPower`** — алгоритм Гёрцеля измеряет мощность на этой частоте в кадрах по 10 мс.
3. **`KeyDetector`** — следит за уровнем шума и сигнала (в дБ) и решает «тон есть/нет»
   с гистерезисом и защитой от дребезга.
4. **`MorseTimingDecoder`** — длительности посылок делит на точки и тире кластеризацией
   последних посылок, по паузам определяет конец буквы (≥2 точки) и слова (≥5 точек).
5. **`MorseCode`** — таблицы русской и международной азбуки.

`MainActivity` читает микрофон через `AudioRecord` (44,1 кГц, источник
`VOICE_RECOGNITION` — без шумоподавления, которое глушит тон) и показывает результат.

## Советы по приёму

- Держите телефон ближе к динамику, уберите посторонний шум.
- Если тон «теряется», увеличьте чувствительность; если появляются ложные знаки — уменьшите.
- Если мешают посторонние тихие звуки, поставьте порог громкости чуть ниже уровня,
  который показывает шкала во время передачи.
- При нескольких станциях выключите авто-частоту и выставьте частоту вручную.
- Первые 1–2 знака после начала передачи могут быть приняты неверно, пока
  приложение подстраивается под скорость.
